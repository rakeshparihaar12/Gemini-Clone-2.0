# 🤖 Gemini Clone

A responsive AI chatbot web application inspired by Google Gemini, built with **React.js** and integrated with the **Google Gemini API**.

## 🌐 Live Demo

👉 https://newgeminiclone.netlify.app/

## 🚀 Features

* 💬 AI-powered chat using Google Gemini API
* ⚡ Real-time prompt and response interaction
* 🎨 Clean and responsive UI
* 📱 Mobile-friendly design
* 🔄 Loading state while generating responses
* 🔐 API key managed through environment variables
* 🌐 Deployed with Netlify

## 🛠️ Tech Stack

* **React.js**
* **Vite**
* **JavaScript**
* **CSS / Tailwind CSS**
* **Google Gemini API**
* **Git & GitHub**
* **Netlify**



## 🎯 What I Built

* Built a Gemini-inspired AI chatbot using React.
* Integrated the Google Gemini API for AI-generated responses.
* Implemented prompt handling and response rendering.
* Managed API credentials using environment variables.
* Configured GitHub and Netlify deployment.
* Created a responsive and interactive user interface.
